# Security Policy

## Supported versions

Security fixes are made to the latest version of the tracker. Older releases may not receive security updates; please update before reporting a problem that may already be fixed.

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in a public issue or discussion. Use GitHub's **Report a vulnerability** option on the repository's Security tab to send a private report:

https://github.com/shivaayguptame-droid/jee-test-tracker/security/advisories/new

Include the affected page, function, or version; the steps needed to reproduce the issue; and its impact. Do not include real user data, passwords, API keys, service-role keys, OAuth secrets, or Google refresh tokens. If private vulnerability reporting is unavailable, contact the repository owner privately through GitHub before sharing technical details publicly.
